
# Usage of AI tools

We use AI tools selectively, focusing on situations where they add efficiency without replacing core problem-solving. AI is useful for structuring issues and pull requests, since it helps make descriptions clearer and more consistent, saving time for reviewers. Here we use whichever LLM the individual developer prefers. We also rely on built-in IDE support, such as IntelliSense, for quick code completion and error detection, which reduces trivial mistakes and speeds up development. AI can also be helpful in drafting documentation or generating boilerplate code where creativity is less important.

However, we deliberately avoid AI for critical logic, design decisions, and domain-specific implementations. Relying on AI here risks introducing hidden errors, poor maintainability, or solutions we don’t fully understand. We also avoid using AI to write tests automatically, since test design requires a deep understanding of requirements. In short: AI supports us as a productivity tool, but it never replaces developer ownership or accountability.
